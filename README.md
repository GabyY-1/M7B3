# M7B3 Maps

Carte satellite fictive de la planète M7B3, construite avec React et Canvas 2D, sans moteur cartographique tiers.

## Démarrage

```bash
npm install
npm run dev
```

Le développement actuel concerne le mode **Satellite**. Le mode **Plan** deviendra principal à la création des pays.

## Géographie de référence

- Rayon : 8 500 km ; diamètre : 17 000 km
- 70 % de mers et océans / 30 % de terres
- 5 continents `C1`–`C5`, 6 océans `O1`–`O6` et archipels
- Pôle Nord partiellement continental, pôle Sud océanique
- Les noms définitifs restent à choisir.

**Important :** les textures et contours affichés sont une première génération procédurale de travail, et non une carte satellite réellement observée ni un jeu de données géodésiques validé. Le projet évoluera vers des couches géographiques mesurables.
